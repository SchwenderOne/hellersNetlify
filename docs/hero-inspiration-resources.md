# Hero Section Inspiration Playbook (Dec 2025)

A curated research packet of high-quality hero/UX inspiration sources we can reference over future sessions. Each entry captures why it matters, the type of aesthetics/interactions it spotlights, and how we should leverage it when crafting new hero concepts for Hellers Kaffees.

## 1. Curated Hero Galleries

1. **Supahero — Website Hero Section Library**  
   - **URL:** https://www.supahero.io  
   - **Why it matters:** Dedicated gallery that filters exclusively for hero sections (Framer, Webflow, custom builds). Great for benchmarking layout archetypes, CTA stacks, and above-the-fold storytelling without digging through entire sites.  
   - **Use it for:** Quick browsing when we need a layout prompt (split hero, storyboard hero, interactive carousel). Screenshot interesting pairings of typography + motion for our mood boards.

2. **Marketer Milk — “30 jaw-dropping hero section examples” (2025)**  
   - **URL:** https://www.marketermilk.com/blog/hero-section-examples  
   - **Takeaways:** Provides case studies (Runway, Glide, Notion, etc.) explaining *why* each hero works (immersive video, dark-theme conversion focus, clutter-free copy).  
   - **Use it for:** Copy tone analysis and CTA framing. Each example highlights narrative hooks (e.g., Runway’s “First Class Amenities”) we can adapt into the café context.

3. **Detachless — “Best Practices & Creative Hero Ideas for 2025”**  
   - **URL:** https://detachless.com/blog/hero-section-web-design-ideas  
   - **Takeaways:** Trend breakdown across SaaS, financial services, creative studios, plus linked Figma templates (Anima, Resumify, Quest). Emphasizes bold typography, interactive proofs, and social proof cells.  
   - **Use it for:** Structural principles (value prop + proof + interface preview). Save Figma links to remix interactions rapidly in future hero experiments.

4. **Unsection — Hero Section Inspiration** *(backup source)*  
   - **URL:** https://www.unsection.com/category/hero-section-design  
   - **Why:** Niche collection grouped by layout type with ability to filter by “Full bleed,” “Split screen,” etc. Useful when we want to compare variations side-by-side.

## 2. High-End Inspiration Feeds (Broader UX but great for hero experimentation)

1. **Godly**  
   - **URL:** https://godly.website (info page: /info)  
   - **Focus:** “Astronomically good” interactive sites curated daily. Highlights highly produced storytelling, motion, and experimental grid work.  
   - **Use it for:** Stretch goals. Capture interaction motifs (3D scroll, cinematic video overlays) we can simplify for the café brand. Bookmark favorites inside their Directory while noting animation patterns.

2. **Hoverstat.es**  
   - **URL:** https://www.hoverstat.es  
   - **Focus:** Alternative/experimental web design feed with dated entries describing unique nav metaphors, kinetic typography, playful micro-interactions.  
   - **Use it for:** Pulling unexpected transitions, hover mechanics, or typographic pacing to avoid “generic agency” visuals. Keep a running list of features we can domesticate for Hellers (e.g., draggable timelines → bean roasting timeline?).

3. **Toools “Ultimate List: 100 Best Inspiration Sites” (2025)**  
   - **URL:** https://www.toools.design/blog-posts/ultimate-list-100-best-inspiration-sites-to-inspire-designers  
   - **Key sections for us:**  
     - *Dark mode websites:* Dark Mode Design, dark.design to fine-tune our night theme.  
     - *Extreme/experimental:* Browsing Mode, The Whimsical Web, Hoverstat.es, Brutal Web for pushing boundaries.  
     - *Standout part libraries:* Supahero (hero), Navbar Gallery, Footer.design, OGimage.gallery for consistent component-language.  
   - **Use it for:** Acts as a meta-index when we need more references (e.g., navs, footers, 404s) to keep the entire experience cohesive once the hero direction is set.

## 3. Resource Working Notes & How to Use Them

| Resource | What to extract | Action items |
| --- | --- | --- |
| Supahero | Layout archetypes, CTA stacks, typography pairings | Build a local inspiration board with 5–7 screenshots tagged by layout type. |
| Marketer Milk article | Messaging frameworks & scroll sequencing | Summarize copy formulas (value prop → proof → action) and test them against Hellers tone. |
| Detachless guide + Figma templates | Interaction patterns + social proof placement | Duplicate relevant Figma files; overlay Hellers palette to see feasibility. |
| Godly | High-motion storytelling ideas | Capture 3 motion references per quarter; annotate which parts are achievable without WebGL. |
| Hoverstat.es | Experimental micro-interactions | Maintain a “wild ideas” log; adapt one concept per hero iteration to keep designs fresh. |
| Toools list & linked micro-galleries | Specific component inspiration (nav, footer, OG images) | When refining beyond hero, pull references from Navbar Gallery, Footer.design, etc., to maintain quality across the page. |

## 4. Next Steps for Hero Redesign Sessions

1. **Assemble an inspiration mood board** (FigJam or local image board) pulling the most relevant references from Supahero, Marketer Milk, and Detachless Figma files. Tag each with the story we want to tell (craft ritual, atlas storytelling, café ambience).
2. **Define hero archetypes** (e.g., cinematic video, split narrative, map-driven) by mapping resource references to the café’s brand pillars.
3. **Prototype quickly** using the Figma templates or Framer-ready kits when available; translate winning concepts into Eleventy-compatible HTML/CSS afterwards.
4. **Document learnings** from each iteration back in this markdown so we can track which resources led to successful experiments.
